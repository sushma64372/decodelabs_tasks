# Data Cleaning and Preparation – DecodeLabs Internship

## Project Overview

This project focuses on cleaning and preparing a raw dataset to make it suitable for data analysis.

## Project Objectives

* Identify and handle missing values.
* Remove duplicate records.
* Correct date formats.
* Validate Order IDs and dates.
* Prepare a clean dataset for further analysis.

## Dataset Information

* Total Records: 1200
* Total Columns: 14
* Dataset: Dataset for Data Analytics.xlsx

## Tools and Technologies

* Python
* Pandas
* Microsoft Excel
* Git and GitHub

## Data Cleaning Steps

1. Loaded the Excel dataset using Pandas.
2. Checked missing values.
3. Replaced missing CouponCode values with "No Coupon".
4. Checked and removed duplicate records.
5. Corrected date formats.
6. Validated Order IDs and dates.
7. Exported the cleaned dataset to Excel.

## Final Results

* Total Records: 1200
* Total Columns: 14
* Missing Values: 0
* Duplicate Rows: 0
* Duplicate Order IDs: 0
* Invalid Dates: 0
