# DATA VISUALIZATION PROJECT REPORT

## 1. Project Title
E-Commerce Data Visualization Using Python

## 2. Introduction
This project focuses on analyzing and visualizing an e-commerce dataset using Python. Different charts are created to understand sales performance, payment methods, order status, and the relationship between quantity and total price.

## 3. Objectives
- To understand the e-commerce dataset.
- To analyze product-wise sales.
- To visualize monthly sales trends.
- To understand payment method distribution.
- To analyze order status.
- To study the relationship between quantity and total price.

## 4. Tools and Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code
- Excel Dataset

## 5. Dataset Information
- Total Records: 1200
- Total Columns: 14
- Dataset Format: Excel (.xlsx)

## 6. Charts Created
1. Product-wise Total Sales – Bar Chart
2. Monthly Sales Trend – Line Chart
3. Payment Method Distribution – Pie Chart
4. Order Status Distribution – Bar Chart
5. Quantity vs Total Price – Scatter Plot

## 7. Conclusion
This project helped in understanding how data visualization makes complex datasets easier to analyze. Different charts were created using Python libraries to identify sales patterns and understand important business information.
