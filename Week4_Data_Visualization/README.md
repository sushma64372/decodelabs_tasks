# E-Commerce Data Visualization Using Python

## Project Overview
This project focuses on visualizing an e-commerce dataset using Python. It uses different charts to understand sales trends, product performance, payment methods, and order status.

## Dataset Details
- Total Records: 1200
- Total Columns: 14
- File Format: Excel

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

## Visualizations Created

### 1. Product-Wise Sales
Bar chart showing total sales for each product.

### 2. Monthly Sales Trend
Line chart showing monthly sales over time.

### 3. Payment Method Distribution
Pie chart showing the distribution of payment methods.

### 4. Order Status Distribution
Bar chart showing the number of orders by status.

### 5. Quantity vs Total Price
Scatter plot showing the relationship between quantity and total price.
