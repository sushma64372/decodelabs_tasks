# Data Analytics – Exploratory Data Analysis (EDA)

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) of an e-commerce dataset to understand sales patterns, calculate descriptive statistics, and identify potential outliers.

## Objectives

* Calculate mean, median, and total order count.
* Identify missing values.
* Detect potential outliers.
* Analyze monthly and yearly sales trends.
* Visualize data using graphs.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* VS Code

## Dataset

* Total Records: 1200
* Total Columns: 14
* Dataset Format: Excel (.xlsx)

## Key Findings

1. Total orders: 1200.
2. Average order price: ₹1053.97.
3. Median order price: ₹823.62.
4. Potential outliers detected: 8.
5. CouponCode contains 309 missing values.
6. Highest monthly sales were recorded in June 2024.
7. Sales fluctuate across different months.

## Visualizations

* Boxplot of Total Price
* Monthly Sales Trend
* Year-wise Sales Analysis

## Conclusion

The analysis helped identify sales patterns, missing values, and potential outliers in the e-commerce dataset.
